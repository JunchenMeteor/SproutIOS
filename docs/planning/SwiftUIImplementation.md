## 1. 任务与产品背景

为家中二年级孩子开发每天至少五分钟目标的英语练习打卡 App，家长管理清华版教材版本和已学进度，孩子做多道短题，通过坦克收藏保持兴趣。用户希望学习 SwiftUI，本仓库必须原生 SwiftUI，支持 iPhone/iPad；另外两仓库为 Python + FastAPI + LangGraph 后端与 uni-app x 跨端客户端（小程序/Web/Android/原生 HarmonyOS NEXT），后端未来个人服务器运行。不要在本仓库用跨端替代 SwiftUI，不用 React Native、端侧模型、Taro 或 Mastra，不换已定后端架构。

所有 AI 转写、语法、专业发音和 TTS 都由后端访问云端。每题按键开始、按键结束，完整录音上传；支持回放/重录。首版不做流式上传、实时字幕、实时对话、自动判停、抢话/打断、自主 agent 或豆包。儿童录音会发送给后端及所选供应商，不能在界面宣称仅本地处理。

基础题完成就打卡，不以分数、录音秒数或评测成功为门槛。额外练习为“再玩一关”。奖励是坦克收藏馆：每日小零件/徽章、累计不同日期解锁真实历史坦克、月度目标涂装/展台；无战斗、抽卡、多币种。建议首次、3/7/14/21/28 日期里程碑，尚可调整，服务端计算，不写死在客户端。

## 2. 设备、环境和权限

设备：MacBook Pro A2251、16GB RAM、512GB SSD，用户记为 2019 年但型号通常对应 2020 年 Intel 13 英寸四雷雳机型，需“关于本机”核对；iPhone 14、iPhone 15 Pro；iPad A1876，2018 年 12.9 英寸第三代 iPad Pro A12X。系统版本待确认。Mac 负责 Xcode 编译、签名与真机测试；Windows 可以审阅设计或开发后端，不能声称 Windows 已完成 SwiftUI 编译。不要建议第一版换设备；先核对可用 Xcode、签名方式和支持版本，再确定 deployment target。

遵守实际 Mac 工作区及目标仓库的 AGENTS.md；应用代码进入用户指定的 Mac 客户端仓库，任务材料放该环境约定的任务目录，文本 UTF-8/LF。G:/开发测试 仅是当前 Windows 规划材料位置，不是 Mac 源码路径。不得访问无关密钥、其他会话路径或改共享依赖。实际路径与创建范围在执行任务中落实；不擅自新建远端仓库。

仅修改客户端仓库；不修改 MeteorVoice，不改后端实现，不部署，不充值，不提交密钥，不擅自提交 App Store/TestFlight。应用会话令牌存 Keychain；厂商长效密钥永远不进 App、源码、日志或 fixture。麦克风和数据授权文案真实；儿童反馈少量文字，敏感操作在家长入口完成。

## 3. 必须随任务取得的材料与契约

同目录 ProductRequirements.md、TechnicalDesign.md、ClientContext.md、ProjectEngineeringStandard.md、ProjectFacts.md、DocumentationAudit.md 和 ../standards/GeneralEngineeringStandard.md 必须提供给本窗口。唯一权威接口是 TechnicalDesign.md 第5节 EC-API-0.1；本文不另定义路径或字段。主题为五配色组十套明暗、默认暖白浅蓝 B，按新规范完整 tokens 与组件行为消费；不能仅硬编码单主题。附件不可用时列出缺失，推进界面/本地录音独立部分，但不能自行发明远端接口。

后端窗口维护 canonical schema/OpenAPI 与共享 fixtures；客户端保存相同 contractVersion 和哈希。每次联调记录后端提交、客户端提交、契约版本。所有修改带 Idempotency-Key，日期由服务端 timezone 规则，课程写入带 expectedRevision。客户端可缓存 summary，不自行永久发奖励，不在重试时生成新的业务完成 ID。已确认打卡优先合并，待同步草稿不被全量刷新覆盖。

接口覆盖 bootstrap/档案/课程进度/每日固定计划、整文件 audio、attempt 与 evaluation 轮询、家长确认转写和受控重试、check-ins 与补卡、collection、TTS 完整音频、sync、backup/report、import preview/commit、deletions。未知枚举和未启用能力安全降级，不能当成功。认证方式未定，只使用明确标注的开发身份，不能把它上线。

接口更改先写提案，说明字段/行为/兼容性及Python后端、SwiftUI、uni-app x三仓库影响；未经确认不兼容变更不实施。不要自动向其他聊天发消息，除非用户明确授权；默认共享文件/变更记录协作。后端可用前以契约fixture开发，不猜供应商字段。后端内部retry_wait/partial_success仍映射API queued/partial，客户端不得接收自行新增enum。

## 4. 页面与本地行为

首次家长设置：教材版本/当前已学课次、儿童昵称和录音保留。教材未确认时明确原创演示；不能内置未许可教材。

每日选择：“学了新内容 / 复习旧内容 / 没上课或不清楚”。新课显示建议下一课，家长确认或修改后请求计划；复习/未知不推进。计划固定并保存版本，题型随机但知识点不得越过已学范围，不允许同日反复换基础题刷奖励。建议时间分配新课 3+1+1、复习 2+3、未知 2+3 分钟，作为软预算。完成条件来自计划，合规跳过须记录原因，不强制录满。

跟读用参考句与原始音频专业评发音，不加冗余语法评分；自由表达先转写原话再文本语法分析，发音另做。App 不根据转写自行评发音。转写不清、噪声或没有供应商置信度时显示不确定；家长可确认文本，不能把纠正句显示成孩子原话。儿童一次最多一个关键改进点，家长可展开真实细节；未支持功能显示暂不可用，不填假分数。

完成页：插画、短动画、具体英语鼓励和下一目标；等待反馈可继续，额外题“再玩一关”。收藏馆已解锁卡与未解锁剪影，零件、坦克、装饰明确。当前不生成历史素材，先用明确演示占位，最终素材许可/历史事实另验收；无真实武器操作。支持减少动态效果、适合儿童的按钮、文字与触控区域。

日历按目标日期，详情显示真实确认时间、客户端完成时间来源和补卡标记。当前连续数/累计日期/当天状态/历史最长数使用服务端结果。建议固定北京时间，换时区不重新打卡；补卡范围从配置读取。断签不丢收藏。

录音使用 AVFoundation 的普通完整文件流程；建议 M4A/AAC，但按后端 audioLimits 与真机结果确定编码。权限拒绝、来电/音频路由切换、后台、中途崩溃、磁盘不足都保留可恢复进度；损坏片段不自动提交。上传前回放/选择最终录音；重录保留明确选中项，废弃片段按清理策略删除。播放示范与录音之间正确管理 audio session，不互相串录。

本地持久化保存计划快照、草稿、录音引用、稳定 UUID/幂等 key、离线完成时间、队列重试状态。录音文件与可清课程缓存分开。客户端开发最低系统确认后选择简单兼容持久化方案，不为流式未来架构增加复杂度。

离线仅对已缓存且完整可用的服务端计划展示“本机已保存，联网后确认”的完成与奖励预览，不赋予永久解锁；首次启动无计划/素材或未联网确认的新课不能自动造正式计划，只能提示联网，或提供明确不保证打卡的本地复习草稿。联网按依赖顺序上传录音/attempt 与完成记录，允许先合法确认打卡再补反馈，重试沿用 ID；服务器已有同日记录则合并，不二次奖励。登录失效保留队列；切账号隔离，未经确认不上传旧账号儿童音频。sync 游标过期重取权威数据，但保留未确认操作并按 revision 解决冲突。

### 4.1 主题、组件与工程实现

设置五配色组×浅深两套与system/light/dark模式，默认sky/system；十theme ID为项目规范表值，group存储键sky/mist/lavender/peach/lemon。配色/模式存本设备，断网可切，不调用主题server API，不强制与另设备同步。Color资源/映射来自完整语义tokens：四背景、三级字/图标、按钮/链接/选中焦点/hover/pressed/disabled/边界遮罩阴影、四状态和录音进度日历奖励；不只变accent，页面不硬编码色，已开弹层/toast/banner立即变。

button/dialog-sheet/toast-banner/form/list-pagination/card-container/recorder/feedback/calendar/reward用稳定输入输出、禁用防连点、loading/empty/error、focus/keyboard/safe-area与响应布局；页面只组合viewmodel与组件。录音/播放/权限/文件/login/theme storage封装平台adapter，业务规则服务器权威，不在Swift与uvue复制奖励算法；可共享行为/素材/API/token，不共享源码。

执行title28/section22/body17/helper14/english24逻辑pt及动态字号，spacing4/8/12/16/24/32，radius12/20/24，主触控>=48；左对齐文本表单标题、录音奖励居中，手机单列/平板限宽可两栏。主按钮accent/#14243B和边框，普通文字>=4.5/必要边界>=3，不能用白字浅蓝按钮。click120–180ms/转场200–300ms/奖励1–2s可跳过，减少动态静态替代；保存确认后播、不靠动画发奖，无假波形/percent、后台停止视觉动画。

每手写文件多行职责头、公共API多行///、复杂逻辑/* */，MARK/directive单行例外；Swift4空格、UTF8无BOM/LF/末尾单换行/无tab尾空格。类型间2空行、函数方法间1、类型函数边界2，注释附声明，无超过2。注释不计、普通blank计、inline代码计1、条件directive计代码；跨extension类型总长不逃限。页面200/300、sharedUI150/200、state/service200/300、model150/250、state-machine120/200、utils/tokens120/200、config150/250、tests250/350，函数30/50、类型150/200、body60、业务嵌套3/复杂度10。按通用规范安全formatter+AST归一/checker幂等检查，工具尚待实现，SwiftLint默认不等于此口径。

## 5. 数据管理不可遗漏

家长可选择长期保留录音，查看云端发送和删除策略。记录回放需有效授权，已删除录音显示不可用，文字反馈可保留。月报 CSV 先行、PDF 可后置并标明能力，但可恢复备份不是月报，基础交付必须能导出记录/反馈/课程进度/奖励证据和选择保留录音并导入恢复。

导出用系统文件分享/保存；下载校验哈希，保护敏感备份；导入先 preview 展示日期去重、冲突、录音缺失和映射，家长明确确认 commit，不自动覆盖。删除音频/儿童/账号有影响说明、必要重新认证和异步状态，防止后台恢复旧备份复活删除项。未定加密容器和账号恢复策略应在接真实数据前确认，不谎称未加密备份已安全加密。

## 6. 阶段、假服务和验收

阶段 0：确认指定仓库与其规则、设备系统/签名、最低系统、契约附件；输出简短实现设计和缺项。不得为了避开 Mac 验证用网页替代正式客户端。

阶段 1：用原创小样和契约固定 fixtures 实现今日入口、录音回放/重录、反馈状态、日历、收藏、家长页和持久化队列。假服务为显式 Debug 模式，覆盖成功、部分失败、无置信度、超时、权限失效、版本冲突、重复日期、离线；界面与报告标“模拟服务”。使用现有 fixture 的 meaningful assertions，不写镜像实现的空洞测试。

阶段 2：与本地真实后端联调，核对完整文件、稳定 ID、轮询有界、同步冲突、多设备同日、补卡、导出导入和删除。真后端如果仍用供应商 mock，结果只标“真实后端/模拟供应商”。禁止把假服务通过称云端评测通过。

阶段 3：取得家长授权和后台已配置真实供应商后小批真机试用。至少在 iPhone 14、iPhone 15 Pro、iPad A1876 核对录音/播放、屏幕布局、横竖屏适配、中断、权限拒绝、离线退出恢复、后台上传可恢复、字节/时长限制、响应等待体验。设备无法接入则明确未验证和需执行步骤，不能伪造截图或日志。

阶段 4：月报 PDF、真实许可素材、无障碍与发布准备；发布渠道/签名/隐私另行确认。不擅自发布。

核心验收：新课只有确认才推进；未知不推进；无需分数即可完成；一次反馈一个重点；离线跨午夜保留 targetDate；同日多设备/重复重试只一份奖励；来电和崩溃不丢草稿；账号切换不串音频；删除后播放失效；备份在空测试档案恢复后日期、反馈、进度一致并且奖励不重复。记录每条是模拟、后端联调、供应商真实还是设备真实。
