# 产品需求：英语练习打卡与坦克收藏馆

2026-10-11补充：系统需能区分各客户端实现、运行平台及发布版本，支持请求/任务/模型调用的问题定位和平台使用统计。具体字段、来源信任边界、统计去重、可选诊断与兼容规则统一见[客户端上下文与追踪](./ClientContext.md)。请求量、安装实例、活跃家长、练习儿童和打卡日期分别统计，不把安装ID当人数或身份；不要求首版建设运营后台或完整点击埋点平台。各客户端命名遵守项目规范的小驼峰/大驼峰分类。

版本：v0.4，2026-10-11。关联接口：EC-API-0.1，唯一权威定义在 TechnicalDesign.md。本文件是需求计划，不是已实现功能说明。当前架构、编码与主题以 ProjectEngineeringStandard.md 为准，通用基线见 ../standards/GeneralEngineeringStandard.md；决策和验证边界见 ProjectFacts.md。本次同步正文的主题、平台与验收，不改接口。

审阅状态：核心范围、异常和验收已形成文档；供应商、设备、真实素材与恢复运行结果仍需开发阶段验证。

## 1. 目标与确定范围

为家中二年级孩子提供每天至少五分钟目标的英语练习，让校内已学知识得到复习，并用同主题趣味任务和坦克收藏激励坚持。家长负责教材进度、档案、录音授权和数据管理；儿童界面低负担、鼓励优先。五分钟由多道短题构成，不连续录五分钟，不强制单题录满秒数或按分数判成功。用户同时希望通过项目学习 SwiftUI。

已确定：三个独立仓库，SwiftUI 原生 iPhone/iPad 客户端（Mac）、Python + FastAPI + LangGraph 后端（Windows，未来个人服务器）、uni-app x 跨端客户端（微信小程序、Web、Android、原生 HarmonyOS NEXT）。所有 AI 转写、语法、发音与 TTS 由后端访问云端。孩子按键开始/结束录音，上传完整文件，允许回放和重录，录完每题后返回反馈，允许部分结果先返。可以在后端并行执行相互独立的评测任务。各跨端编译模式和版本未实测。

不在首版范围：端侧模型、React Native、Taro、Mastra、TypeScript 后端、豆包、流式上传、实时字幕、实时语音对话、自动判停、抢话/打断、自主规划 agent、战斗/抽卡玩法、拍课本自动推进课程。小程序/Web 属于 uni-app x 仓库，不代替 SwiftUI。不能因“以后可加”把这些排除项纳入首版基础设施。

后端语言和框架已确定；数据库、仓库名称、登录方式、域名、服务器配置、最低系统、uni-app x 版本/编译模式与发布渠道未定。工程设计为五配色组十套主题，默认暖白浅蓝 B，详见新项目规范。建议和待确认统一见 README.md。

## 2. 用户流程与页面

家长首次设置：建立家长账号和儿童档案 → 选择已确认版本教材 → 设置当前已学课次 → 查看云端录音处理说明、选择长期保留策略 → 进入儿童练习。教材来源和许可未齐全时使用明确标注的原创演示，不冒充课本。

每天入口只有三个低负担选择：

1. “学了新内容”：显示建议下一课，家长确认或改课次后才推进已学范围；不能以点击入口自动判定下一课已学。
2. “复习旧内容”：在已有范围选题，不推进课程。
3. “没上课或不清楚”：按到期复习与已学主题扩展安排，不推进课程。

练习页：听示范或看任务 → 点开始录音 → 点结束 → 回放/重录/提交 → 看到一个关键改进点和具体鼓励 → 下一短题。跟读有参考句；自由表达有主题提示，允许短句，不诱导儿童提供真实姓名、学校、位置等信息。重录保留最终选择，不能靠反复换题重复发奖励。

结束页：基础题完成就打卡，展示坦克插画、短动画、具体英语鼓励、下一解锁目标；额外练习按钮为“再玩一关”。评测未完成或失败不挡打卡，显示“反馈稍后送达”。离线时显示“已在这台设备保存，联网后确认”，收藏动画可以预览，但不能把待确认解锁当作跨设备永久资产。

主要页面：今日练习、练习题、完成页、日历与记录详情、收藏馆、家长管理。记录详情支持录音可用时回放及反馈；录音已按策略删除时明确说明，保留的文字反馈仍可查看。家长页含进度、档案、录音策略、导出恢复与删除入口。

### 2.1 平台与设置的产品行为

SwiftUI iPhone/iPad 与 uni-app x 的微信小程序/Web/Android/原生 HarmonyOS NEXT 承载相同练习、日历、反馈、收藏和家长管理语义；Apple 用原生实现，跨端按平台 adapter 实现，不要求共源码或完全相同像素。纯鸿蒙需独立安装/运行验收，不能以 Android APK 代替。平台未支持的录音/文件能力应明确提示，不能假装已完成上传；Web 录音单独实现。

设置提供五配色组和 system/light/dark 三模式：晴空蓝/午夜晴空、雾蓝晨光/深海星光、薰衣草/紫夜银河、蜜桃奶油/琥珀夜色、柠檬晴日/石墨冰蓝，共十套。默认 Sky 组（存储键 sky）、跟随系统；浅色为暖白+浅蓝 B，深色为午夜晴空。选择按本设备保存，断网可切，不强制跨设备同步，不新增 server 主题 API。

每套主题必须完整覆盖 page/card/elevated/input、三级文字/图标、按钮/链接/选中/焦点/hover/pressed/disabled、边界/遮罩/阴影、四状态色、录音/进度/日历/奖励；精确值与组合唯一来源为项目规范第6节，不能只换 accent/bg。切换后已打开 dialog/sheet/toast/banner 同时更新；页面无硬编码色。学习页简洁，奖励页有可跳过的精彩动画；减少动态效果有静态替代，状态确认后才播，动画不发奖。

普通正文对比 >=4.5、大字 >=3、必要控件边界 >=3，颜色不是唯一状态标识；浅蓝主按钮使用 #14243B 字与深边框，不用白字。动态字号、英文显示、儿童主按钮至少48逻辑单位、键盘/焦点/安全区必须可用；手机单列，平板/桌面限宽可两栏。配色数值通过不等于真实界面无障碍通过。

## 3. 课程和选题

主线为清华版二年级英语教材，版本、上下册、ISBN 与当前课次需确认。第二部分为同主题原创或合法授权趣味扩展，不直接塞入整套国外教材。Everybody Up、Kid's Box、Oxford Discover、Our World 只是综合课程参考候选，RAZ 是分级阅读参考；没有确定采用哪套，也没有“国内主流排名”或“国外统一教材”的结论。

题目关联教材版本、课次、知识点、已学前置条件、类型、参考文本/提示、建议用时、素材来源/许可及版本。知识点有序；随机化只改变题型、顺序和已学范围内的表达，不随机引入未学新词。同一目标日期固定基础计划快照，额外题另标记；重新打开或换设备不反复重抽基础计划刷奖励。

建议时间分配可配置：新课日 3 分钟新课 + 1 分钟旧课 + 1 分钟应用；复习日 2 分钟巩固 + 3 分钟趣味；未知日 2 分钟到期复习 + 3 分钟已学扩展。时间为引导预算，不是录音长度门槛。题量按孩子实际速度调节；家长可降低难度或跳过不适合题目并记录原因。基础完成规则由计划声明，用户确认后的有意完成/跳过计入，不把纯打开页面当练习，不依赖 STT、分数或云端成功。

## 4. 反馈规则

跟读：原始录音 + 参考句交专业发音评测，主评发音，不对照读正确句子做冗余语法评分。

自由表达：STT 保留可识别的儿童原话 → DeepSeek 分析语法、用词并给短鼓励；发音单独用原始音频评测。STT 可能自动纠错，识别不确定、噪声和漏识别不能直接算语法错误。没有供应商置信度字段时不能伪造百分比；证据不足标为“听得不够清楚，请回放确认”，不扣分。允许家长确认或修正转写；修订版本触发受控重新分析，原始识别文本保留来源标记，不无限重复调用。

原始音频至少保留至评测进入终态及配置的处理/重试窗口结束；不能用识别文本冒充发音判断。自由表达发音能力必须实测验证：供应商不支持时显示暂不评发音，不用通用音频理解或强制对齐假造音素评分。

儿童每题最多一个关键改进点，反馈短、具体、友好，不用低分羞辱孩子；家长可查看词/音素细节、原话和改写、供应商与任务状态。不同厂商分数不得直接比较或合成统一准确率；示例评分只能明确标为模拟数据。

## 5. 打卡、补卡和奖励

以下是业务设计初稿，需要上线前确认。目标练习日期 targetDate、客户端声明完成时间 clientCompletedAt 与服务端确认时间 confirmedAt 分开保存；时间戳使用 UTC，业务日期建议固定 Asia/Shanghai。手机时区变化不改变既有目标日期或奖励。服务端校验日期范围；未来日期不允许打卡。补卡范围待确认，首版必须提供可配置范围而不是客户端任意回填。

当天打卡：服务器收到且确认当前北京时间目标日期的基础完成记录。离线完成为待同步，保留实际客户端完成时间但标为客户端声明，不能声称服务端确认时间等于孩子真实操作时间。

累计：已确认完成的不同目标日期数量，补卡也只计该日期一次。重复提交、跨设备提交、追加练习不增加日期数量。补卡事实根据目标日期早于服务器确认日记录，并可显示客户端声明的实际完成时间；不得伪装成当日签到。

连续天数建议：已确认目标日期的连续日期链，补卡可补齐链，但日历保持补卡标记。当前连续数从今天开始向前计算；今天未完成时从昨天开始，昨天也缺失则为零。历史最长链单独记录。与累计收藏不同，断签只影响连续数，不清空已得奖励。若用户希望补卡不修复连续数，需更改契约版本与两端显示规则，不能各算一套。

奖励唯一由服务端计算与确认，儿童离线只见暂存展示。每次首次日打卡获得小零件或徽章；累计日期解锁真实历史坦克；月度目标得到特别涂装/展台。建议首次打卡即解锁入门坦克，后续累计 3/7/14/21/28 日期解锁，可配置。每日零件是纪念收藏，不引入多币种商城。完整坦克、零件/徽章、涂装/展台三个层级明确，无付费抽卡、无重复发奖。

月度目标建议按 targetDate 所属自然月的唯一完成日期计算，补卡可达成该月目标；奖励账本以儿童、逻辑奖励权益和目标月份/日期/里程碑形成稳定去重键，规则版本另作审计快照；配置升版不重复授予同一权益，重试与规则重算均去重。月度具体目标及可补发期限待确认。

收藏馆显示已解锁详情和未解锁剪影；统一美化插画，卡片含型号、年代、国家和简短工程特点。历史事实需来源核对，素材需许可记录，不提供真实武器操作指南。当前不爬素材或生成图；动画尊重减少动态效果设置。

## 6. 异常、数据与家长控制

| 情况 | 必需行为 |
| --- | --- |
| 断网/后台退出 | 保存草稿、录音及待同步操作；恢复后接续，不重复发奖 |
| 来电、麦克风拒绝、空间不足 | 解释原因，保留可恢复进度；中断片段由孩子确认重录，不提交损坏文件 |
| 上传/评测超时、额度不足 | 可以继续题目并打卡；反馈标出未完成部分，重试有上限 |
| 两设备课程修改 | 返回版本冲突，家长选择；不能静默覆盖已学进度 |
| 登录过期 | 待同步数据保留，重新认证后只归属原账号；切换账号不能自动上传旧儿童录音 |
| 删除期间有排队任务 | 取消后续调用并阻止结果回写；已发送供应商部分按其规则追踪删除 |

离线继续正式练习须已有完整缓存的服务端计划及素材；首次启动无计划、未联网确认的新课不保证离线打卡。Web浏览器存储可能受配额/系统清理影响，界面需明确未同步风险；uni临时录音必须转存，不能只保存临时路径。

客户端缓存课程音频、草稿、录音和待同步记录；服务器是多设备权威记录和备份。云端调用会把录音发送给对应供应商，不能因本地缓存宣称录音不上传。家长明确选择长期保留策略，可修改与删除。不同儿童与家长之间严格权限隔离。短期处理保存与长期收藏保存分开说明，服务器备份轮换和厂商残留期限也需列出。

可恢复备份必须包含教材/题目版本引用、课程进度、日期记录、反馈、收藏账本、必要映射及选择保留的录音；提供版本、校验和、导出范围、录音缺失说明。导入先预览，确认后恢复到当前家长有权管理的儿童档案；同日期去重，已有更新内容不静默覆盖，不能导入奖励凭空增值，服务端按恢复记录重建并去重。备份不含 API 密钥、会话令牌或其他家长的数据。

月度报告支持 CSV 或 PDF 查看；建议先 CSV 后 PDF，但二者与可恢复备份是不同功能，不能拿月报代替恢复能力。删除支持单录音、儿童档案及家长账号，解释影响和完成状态。删除的录音在播放与备份入口失效；恢复旧备份必须是家长显式操作，不能后台自动复活已删除数据。

## 7. 分阶段交付和验收

A：原创小样 + 假服务验证 SwiftUI 与 uni-app x 各目标端录音、课程选择、反馈状态、收藏、主题与离线草稿；按实际端逐项记录，明确没有云端真实性结论，不以一个端 mock 通过代替四端能力。

B：后端本地运行 + 契约联调，验证多设备、幂等、补卡、版本冲突、有限重试、权限和可恢复备份。模拟供应商只验编排，不验发音质量。

C：经家长授权的真实儿童录音、已确认真实 API 账户，小批试用专业评测/STT/TTS；确认成本限制与效果，再接入日常使用。评测失败仍可打卡。

D：月报 PDF、素材与内容完善；发布准备另行确认。不能因为 PDF 后置而将可恢复备份从 B 阶段删除。

验收必须覆盖：家长确认新课才能推进；未知不推进；未学知识不被抽到；短题按键录音可回放重录；跟读不额外语法打分；噪声不冤枉语法；离线完成可恢复；补卡日期/实际时间清楚；同日多设备只发一份奖励；跨北京时间午夜与换时区无重复；断签不丢累计；备份导出到空测试环境再导入后关键记录一致；未选择录音和已删除录音不被悄悄带回；儿童反馈一次一个要点；无厂商密钥进入 App 或日志。

真实选型使用同批儿童录音与家长人工参考，覆盖正确读音、已知错误、漏词、噪声和重复样本；分别记录冤枉正确发音、漏判真实错误、转写保真、重复稳定性、等待时间分布和实际账单费用。阈值经试验确认，不承诺固定延迟/月费，不以营销准确率或跨厂商分数定胜负。

新增验收：五组×两明暗×主要组件状态，弹层已开时切主题、system模式改变、设备本地保存、离线切换、动态字号/读屏/键盘/安全区、减少动态效果；主题不进入云端课程/打卡状态。小程序/Web/Android/原生鸿蒙分别报告录音、权限、文件、登录、重录、上传、恢复与布局结果；SwiftUI Mac编译及各真机另列。三消费者同契约版本/哈希，无客户端各算奖励。工程质量包含业务模块边界、平台adapter集中、多行注释、注释排除/普通空行计入、type2/function1及有效行门禁；这些是待实施检查，不是已有工具通过。
